## Technologies & Tools Used

- **Markup & Styling:** HTML5, Modern CSS3 (CSS Grid, Flexbox, Gradients, Custom Properties)
- **Scripting Language:** Modern JavaScript (ES6+)
- **Core APIs & Features:**
  - Dynamic DOM Manipulation (`document.createElement`, `appendChild`, `replaceChild`, `remove`, `innerHTML`)
  - Event-Driven Programming (`addEventListener` for `click`, `input`, `change`, `focus`, `blur`, `submit`, `keydown`)
  - Regular Expressions (`RegExp` syntax, pattern matching, RFC email validation, capture groups)
  - Higher-Order Array Iterators (`map`, `filter`, `reduce`, `forEach`, `find`)
  - Math & Number Utilities (`Math.min`, `Math.max`, `Number.isFinite`, `Number.isInteger`, `.toFixed(2)`)
  - Web Storage API (`localStorage`, `sessionStorage`)
  - Asynchronous AJAX & HTTP (Native `fetch()`, `async/await`, jQuery `$.getJSON()`, `$.ajax()`, Node.js `http`)
  - Timing API & Architecture (`setInterval()`, `setTimeout()`, ES6 Modules `export`/`import`)
- **Development Environment:** Visual Studio Code / Antigravity IDE
- **Version Control:** Git & GitHub
